FOCUSMETER 3.3 — WINDOWS / PYTHON
==================================

Готовая версия (Windows x64): распакуйте ZIP и откройте FocusMeter.exe.
При переходе с предыдущей версии сначала выйдите из неё через значок в трее.

Для запуска из исходников нужно: Python 3.10+ (с Tkinter). Остальное (pystray, pillow) поставится само.

Запуск:
1. Распакуй папку куда угодно.
2. Дважды нажми "Запустить_FocusMeter.bat".
3. Появится окно и значок в трее (стрелка ^ справа внизу).

Как это работает:
- Закрыл окно крестиком — счёт времени продолжается в фоне (значок в трее).
  Полностью остановить можно только через правую кнопку по значку -> "Выйти".
- Клик по значку в трее — открыть окно. Правая кнопка — Пауза / Выйти.
- Настройки -> "Запускать вместе с Windows" — стартует сразу в трей.
- Приложения, в которых ты был меньше минуты, в списках не показываются.
- Тема (светлая / тёмная) — в Настройках.

Данные: %LOCALAPPDATA%\FocusMeter\usage.db
Иконки приложений: %LOCALAPPDATA%\FocusMeter\icons
Журнал ошибок: %LOCALAPPDATA%\FocusMeter\error.log  (если что-то не работает — пришли его)

Приватность: нет кейлоггера, скриншотов и чтения содержимого страниц.
Учитывается только название программы и заголовок окна, пока ты не бездействуешь дольше порога из настроек (по умолчанию 60 секунд).
